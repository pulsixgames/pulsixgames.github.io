# Level 67

Clean browser build prepared for GitHub Pages and jsDelivr.

## Files

- `index.html` is the entry point.
- `game.js` loads the split Unity build files from `Build/`.
- All large Unity files are split into parts under 20 MB.
- XML wrappers, external ad frames, advertiser scripts, and remote CDN references were removed.

## Hosting

Push this folder to GitHub, then load it with GitHub Pages or jsDelivr. Keep the folder structure unchanged.
